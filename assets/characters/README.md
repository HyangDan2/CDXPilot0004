# Lumi Character Asset

`lumi-expressions.png` is the original transparent 3-by-3 expression sheet generated for Particle Beat with the built-in image_gen tool on 2026-10-17. It is a project-local asset; no generation service is called during gameplay. CSS selects equal grid cells without modifying the source image.

Row-major mapping: idle, perfect, good, miss, worried, failed, clear, ready, blink. MascotReaction prioritizes MISS over PERFECT over GOOD within a feedback batch, retains stronger reactions for 400ms, and returns to worried below 26 health or neutral/blink otherwise. Countdown and pause override with ready; terminal results override with failed/clear. Reduced motion disables the CSS bounce/nod.
